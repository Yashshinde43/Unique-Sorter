Step 1 — Give Admin Full Access to All Enquiry Forms

Backend implementation tracker. Admin role bypasses ownership checks; non-admin users only see and edit enquiries they created. 7 steps to implement, each with exact file, line number, and code diff.

● Backend only Phase 1 · Delivered (refinement) Shared with Frontend
Implementation progress 0 / 7 steps complete

Current Status — What's Broken Today

  • GET /api/v1/enquiry (list) — returns ALL enquiries to ANY authenticated user. No ownership filter. Any user sees every enquiry in the system.
  • POST /api/v1/enquiry (create) — does not store createdBy. There is no way to know who created an enquiry.
  • GET /api/v1/enquiry/[id] — any user can read any enquiry by ID. No ownership check.
  • PATCH /api/v1/enquiry/[id] — any user can edit any enquiry. No ownership check.
  • DELETE /api/v1/enquiry/[id] — already uses verifyAdmin(). Correct. No change needed.
1.1
Set createdBy on enquiry create
Every new enquiry must record who created it. Add createdBy (UID) and createdByName (phone) to the .add() payload in POST.

1.2
Filter enquiry list by role
Admin sees all enquiries. Non-admin users see only enquiries where createdBy === their uid. Add a .where() clause conditionally.

1.5
Create Firestore composite index
The filtered query in step 1.2 (.where('createdBy', '==', ...).orderBy('createdAt', 'desc')) requires a composite index. Without it, Firestore returns an error with a link to auto-create it. Create it proactively to avoid runtime errors.
Collection: enquiry Fields: createdBy ASC + createdAt DESC

1.6
Backfill createdBy on existing enquiries
Existing enquiry documents have no createdBy field. After deploying steps 1.1–1.4, non-admin users will see ZERO existing enquiries (because createdBy is missing). Run a one-time migration to set createdBy on all old docs.
Run: node unique-backend/src/scripts/backfillCreatedBy.js Type: one-time migration
Migration script
// unique-backend/src/scripts/backfillCreatedBy.jsimport { adminDb, adminAuth } from '../lib/firebase-admin';async function backfill() {  const snap = await adminDb.collection('enquiry').get();  const adminUid = process.env.ADMIN_UID; // set in .env  let count = 0;  for (const doc of snap.docs) {    const data = doc.data();    if (!data.createdBy) {      await doc.ref.update({        createdBy: adminUid,      // assign to admin        createdByName: 'admin (backfilled)',      });      count++;    }  }  console.log('Backfilled ' + count + ' enquiries');}backfill().then(() => process.exit(0));
