Phase 1 vs Phase 2 — What Client Agreed in First Meeting

Clear separation of what falls under Phase 1 and Phase 2 based on the first meeting discussion only. Use this to tell the client: "Sir, you said Phase 1 is this and Phase 2 is that."

Phase 1 — Build First Phase 2 — Build Later
Phase 1 — Build First

Enquiry → Quotation → Share → Follow-up

Client agreed that Phase 1 is the complete basic flow: A sales person generates an enquiry, creates a quotation from it, shares it via WhatsApp/Email with catalogue, and sets up follow-up. This is the minimum the field team needs to start working.

1 Enquiry Generation Form — Customer details, model, size, commodity, mandatory/optional fields
2 Quotation Generation — Linked to enquiry, two formats, region-wise pricing, price edit, PDF output
3 Share via WhatsApp + Email — Send quotation + catalogue/brochure together
4 Follow-up Tracking — Follow-up date compulsory after quotation, % chances filled during follow-up
📝

Phase 1 — Part 1: Enquiry Generation Form

No Shortcut — Quotation Only After Enquiry
"There is no shortcut." A quotation can only be created if the customer's enquiry exists first.
Client said: "Enquiry generated form mein customer ke entry rahe toh hi quotation banega. There is no shortcut."
Enquiry Sources
Enquiries come from: Field Engineer visit, Telephone call, Website, Email. All must be entered into CRM manually in Phase 1.
Enquiry Form Fields
Client discussed each field and decided mandatory vs optional:
FieldStatusClient's Words
Customer NameMandatoryBasic identification
Mobile NumberMandatoryUnique identifier & links to quotation
Address / StateMandatoryNeeded for region-wise pricing
Model (Pinnacle / Nandak)Mandatory"First question hai sir — machine model"
Size (4/5/6 Chute)MandatoryDetermines pricing
CommodityMandatoryRice, Pulses, Multi-product
QuantityMandatory"99% cases will be one only"
GST NumberOptional"GST aane mein 2-3 mahina lagta hai"
Email IDOptional"Don't make it mandatory"
Pin CodeOptional"Rahe toh achha hai"
% ChancesOptional"First instance pe we cannot write this"
Month of OrderOptionalSame — cannot judge at first call
Incomplete Enquiry Allowed
If customer just says "mujhe machine chahiye" on phone — allow partial entry. Mandatory fields must be filled, optional can be blank. Forces sales person to go back and collect info.

Phase 1 — Part 2: Quotation Generation

Link Quotation to Enquiry — No Double Entry
Search by mobile number, name, email, or reference number — auto-fills all customer data from enquiry. No re-typing.
Client said: "Simplifying double entry. Enquiry ke paas ek baar poora enter karo, phir quotation mein enter karo — agreed? Can we simplify that way?"
Auto-Generated Reference Numbers with State Code
Every enquiry & quotation gets auto-generated reference number. Quotation reference includes state code: Odisha = "OD", Telangana = "TG".
Client said: "Quotation reference number — if it is Orissa, it has to come with some OD. Telangana TG."
Two Quotation Formats
Single Page: Quick quotation for budgeting discussions.
Multi-Page (Detailed): Full professional quotation with features, 3-4 pages. Different for Pinnacle vs Nandak.
Client said: "Kuch logo ko detail dena nahi chah rahe. Bada customer chahta hai professionally present karna — usmein poora detailing. 2-3 page mein."
Region-Wise Pricing — Auto-Fill
Prices vary by region. System auto-fills standard price based on customer's state. Each region has different pricing.
Client said: "Every region has got its own quotation prices. Jena — Odisha, take prices of Odisha."
Price Modification Before Generating
After auto-fill, system asks: "Do you want to change the price?" If Yes → allow edit. If No → generate with standard price.
Client said: "It will automatically pre-fill with the standard price. Usko chahe toh back karke change kar sakta hai. Turant PDF ban jayega."
Standard Terms Auto-Fill
Same for every quotation:
• Payment Terms — Standard (same for all regions)
• Warranty — Standard 1 year
• Bank Details — Standard
Output — Instant PDF
System generates PDF quotation instantly. User can preview and then share.
📩

Phase 1 — Part 3: Share via WhatsApp + Email

WhatsApp + Email — Both Options
Send quotation via WhatsApp or Email or Both. 80% customers prefer WhatsApp.
Client said: "80% log WhatsApp prefer karte hain. Already number toh diya hua hai, we just skip one and it will go."
Auto-Attach Catalogue / Brochure
When sending quotation, automatically attach matching catalogue. Pinnacle → Pinnacle brochure. Nandak → Nandak brochure. Two files go to customer: Quotation + Catalogue.
Client said: "Jab bhi quotation ja raha hai, catalogue pe aa jaana chahiye. Log quotation bhej dete hain, catalogue bhejana bhool jaate hain. It makes no sense."
📅

Phase 1 — Part 4: Follow-up Tracking

% Chances & Month of Order — NOT at First Enquiry
At first phone call you cannot judge % chances. These are optional at enquiry. They get filled during follow-up.
Client said: "First instance mein jab phone mein baat kar rahe hain, uska chehra toh padh nahi sakte. So it is not correct to enter this at this stage. This can be optional fields."
Follow-up Date — Compulsory After Quotation
Once quotation is sent, follow-up date is compulsory. During first follow-up, user fills % chances (20%, 10%, 5% etc.) and expected month of order.
Client said: "Follow-up date — ye compulsory hai woh add hona chahiye. First follow-up mein usko maloom ho jaana hai — 20% chance, 10% chance, 5% chance, jo matlab hai woh likh ke."

Phase 2 — Build Later

Things Client Said "Not Now — Do It Later"

These items came up in the first meeting but the client explicitly said to keep them out of Phase 1. The exact quote: "Pehla first phase mein inko itna tak scope dete hain, jitna abhi discuss karein utna scope dete hain." (Give them only this much scope in the first phase — whatever we discuss now.)

1 Online Enquiry → CRM Auto-Integration — Website form auto-flowing into CRM
2 Region-Based Auto-Assignment — Andhra enquiry auto-goes to Andhra manager
3 MIS Reports & Enquiry Sheet Reports — Regular interval reporting
⚠

Phase 2 — Items Deferred by Client

Online Enquiry Integration (Website → CRM)
Auto-routing online enquiries from website into CRM was discussed. Client said it's too complex for Phase 1 — keep it separate.
Client said: "Pehla first phase mein inko itna tak scope dete hain. Online ka kuch apan point out karke — itna complicate hai."
Region-Based Auto-Assignment of Enquiries
When an enquiry comes from Andhra, it should auto-go to the Andhra regional manager. Client mentioned it but said do not include in Phase 1 to keep things simple.
Client said: "Agar Andhra ka hai toh mere ko aayega — toh aap check kar lenge. Woh raha. Itna complicate hai."
MIS Reports & Regular Enquiry Reports
Regular interval reports showing enquiry status were discussed. Client mentioned "report aata hai" but agreed this comes after the basic flow (enquiry → quotation → share) is working.
Client said: "Regular intervals mein ek enquiry sheet generate ho ke report aata hai — tab hum woh data column mein rahega."
