This document outlines the agreed scope of work for the Unique Sorter CRM Application, divided into three phases. Each phase has a clearly defined set of features that will be delivered, along with features that are explicitly excluded from that phase.

By signing this document, both parties confirm that they understand and agree to the scope defined for each phase. Any feature not listed as "Included" in a phase is not part of that phase, regardless of prior verbal discussions.

Phase 1 — Delivered & Complete

Enquiry → Quotation → Share → Follow-up

The complete basic CRM flow: a sales person generates an enquiry, creates a quotation from it, shares it via WhatsApp/Email with catalogue, and tracks follow-ups. This phase has been completed and delivered.

# Feature Status
1 Enquiry Generation Form
Customer name, mobile, address/state, model (Pinnacle/Nandak), size (4/5/6 chute), commodity, quantity. GST, email, pin code, % chances, month of order as optional fields.		 INCLUDED
2 Quotation Generation
Linked to enquiry (no double entry), auto-generated reference number with state code, region-wise auto-pricing, price modification before generating, standard terms auto-fill (payment terms, warranty, bank details), instant PDF output.		 INCLUDED
3 Share via WhatsApp + Email
Send quotation PDF via WhatsApp or Email. Auto-attach matching catalogue/brochure (Pinnacle brochure for Pinnacle machines, Nandak brochure for Nandak machines).		 INCLUDED
4 Follow-up Tracking
Compulsory follow-up date after quotation is sent. During follow-up, user fills % chances (5%, 10%, 20% etc.) and expected month of order. Pipeline stage tracking.		 INCLUDED
5 Email Notifications
Automated email notifications for 3 key CRM events via Resend. 		INCLUDED

  • Online enquiry auto-integration (website → CRM)
  • Region-based auto-assignment of enquiries to managers

  • Mobile application (Android / iOS)

Phase 2 — Next

Inventory Management + Sales Invoice + Delivery

Extends the existing CRM pipeline beyond quotation. Adds sale conversion, invoice generation, inventory tracking for machines in the warehouse, and delivery management. Starts after Phase 2 payment is received.

# Feature Status
1 Sales Invoice Generation
When a quotation converts to a confirmed sale, the system generates a sales invoice. This completes the pipeline: Enquiry → Quotation → Sale → Invoice.		 INCLUDED
2 Inventory System (Machine Tracking)
Track machines in the godown/warehouse. Each machine entry includes serial number, model, and availability status (Available / Booked / Delivered). 		INCLUDED
3 Machine Booking on Sale
When a sale is confirmed, a specific machine from inventory gets booked to the customer. System shows: which machine is booked to whom, whether the machine is available or booked, and the delivery date.		 INCLUDED
4 Delivery Tracking
Track delivery dates for booked machines. Visibility into upcoming deliveries and their status.		 INCLUDED
5 Multiple User Roles
Different access levels for Warehouse Manager and Owners. Exact permissions to be detailed in a follow-up requirements meeting before development begins.		 INCLUDED
6 Linked Pipeline
Inventory is directly connected to the CRM pipeline. When a sale happens through the CRM, inventory updates automatically. No separate data entry required.		 INCLUDED

  • Mobile application (Android / iOS) — this is Phase 3
  • Online enquiry auto-integration (website → CRM)
  • Region-based auto-assignment of enquiries
  • MIS reports & analytics dashboards
  • Accounting / GST filing integration
  • Any feature not explicitly listed above as "INCLUDED"

Terms & Conditions

  1. Scope Freeze: Once a phase begins development, the scope for that phase is frozen. No additional features will be added without a separate written change request and revised cost estimate.
  2. Change Requests: Any feature or modification not listed under a phase's "INCLUDED" items requires a formal change request. Change requests may carry additional cost and timeline adjustments.
  3. Payment Before Work: Development for each phase begins only after the full payment for that phase has been received. Partial payments do not initiate development.
  4. Phase Independence: Each phase is an independent unit of work. Completion of one phase does not obligate either party to proceed with the next phase.
  5. Exclusions Are Final: Items listed under "NOT Included" for a phase are explicitly outside the scope. If the client requests these during the phase, they will be treated as a change request.
  6. Detailed Requirements Meeting: Before Phase 2 and Phase 3 development begins, a detailed requirements meeting will be conducted to finalize specific field-level details, user role permissions, and workflow steps within the agreed scope.
  7. Delivery & Acceptance: Upon completion of each phase, the client will be given a reasonable period (7 working days) to review and accept the deliverables. Feedback within this period will be addressed if it falls within the agreed scope.
  8. Technology Stack: Web CRM is built on React (Next.js) with Firebase backend. Mobile app (Phase 3) will be built with Flutter. Any request to change the technology stack is outside the scope of this agreement.
  9. Hosting & Infrastructure: Firebase hosting and infrastructure costs are borne by the client. The developer will assist in setup but ongoing cloud costs are the client's responsibility.
  10. Verbal Discussions: Only features documented in this signed agreement are considered in scope. Verbal discussions, meeting conversations, or informal messages do not constitute scope changes unless formally documented and signed.
