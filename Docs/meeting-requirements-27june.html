1

Admin & Permissions

Why do this first? — The client repeatedly asked for Admin-level control over settings, fields, and data. All other features depend on who has access to what.
Step 1
Give Admin Full Access to All Enquiry Forms
Admin should be able to view, edit, add, and change any field in every enquiry form — including enquiries created by other users.
Step 2
Only Admin Can Delete Enquiry Forms
Remove the delete option from normal users. Only Admin should be able to delete enquiries. The client said: "He may confirm that this order has been lost to competition or the requirement has been dropped — only then the boss will delete it."
Step 3
Bank Details — Admin Only
Bank details in the quotation should be editable only by Admin. If bank details change, Admin updates it — no need to contact developer.
Step 4
Admin Access to Add/Edit States, Lead Sources & Dropdown Values
Client explicitly asked: "This access we need." Admin should be able to add/edit states, lead sources, and other dropdown values. Currently only developer can change these.
Client said: "Aaj hum do state mein kar rahe hain, kal hum teen state mein karenge — ye sab kahan set kar payenge? Ye access humko chahiye."
Step 5
Admin Access to Add/Edit Models, Sizes & Pricing
Admin should be able to add new machine models, new sizes, and set/update pricing from a settings panel. Currently developer has to do this manually.
Client said: "Future ke liye agar humko add karna hai toh uska access hum mein rahe toh zyada better hai taki hum kabhi bhi edit kar sakein."
Step 6
Admin Access to Mandatory/Optional Field Settings
Admin should decide which fields are mandatory and which are optional in the enquiry form.

2

Enquiry Form Changes

Why do this second? — The enquiry form is the foundation of the CRM. All data flows from here to quotations, reports, and sharing. Fix the form structure before building features on top.
Step 7
Add "Existing Customer" in Lead Source Dropdown
Add "Existing Customer" as a new option in the Lead Source / Type of Leads dropdown. Current options: Cold Call, Reference, Referral, Online Website, Social Media, Others.
Step 8
Follow-up & % Chances Fields — Show in BOTH Immediate and Future
The follow-up date field and percentage chances of order field should appear in both "Yes Immediately" and "No Future" enquiries — not just in Future.
Client said: "Customer bolega immediate hai but woh kai baar immediate nahi hota. Today it could be immediate but after a week we realize it got postponed to future."
Step 9
Remark Field — Mandatory with Log History
The Remark field must be mandatory. When a user adds a new remark, previous remarks must NOT be deleted. All entries should form a timeline log with dates.
Client said: "The second entry should not overwrite the first one. What was the first discussion that should be there, second discussion should be there, and a list should form. So that we will know the history of the discussion."
Step 10
Complete Edit Log History (Admin Only)
Every change to an enquiry should be automatically logged — what field was changed, old value, new value, who changed it, and when. This log is visible only to Admin.
Currently
No record of who changed what. Only "last edited" timestamp.
After Update
Admin sees: "Raj changed Model from Pinnacle 6 to Nandak 5 on 25 June at 3:30 PM"
Step 11
Add Negotiated Price Field
Add a field for the negotiated price alongside the standard area-specific price. As discussions happen, the quoted price may change — this field tracks what price was actually offered to the customer and at what stage.
Step 12
Commodities List — Make Flexible / Editable
The commodities dropdown (Rice, Pulses, etc.) should be editable by Admin. They may need to add more commodities like Maize, etc. Keep it as dropdown to maintain uniform naming.
Step 13
Download Options — Add CSV & Excel Both
Enquiry data download should support both CSV and Excel formats. Add a PDF download option as well.
↓ ↓ ↓
3

Quotation — Terms & Conditions

Why do this third? — The quotation pulls data from the enquiry form. Now that the form is correct, we can fix what appears in the quotation terms.
Step 14
Freight — Two Options: Inclusive & Extra at Actuals
Give user two options for freight:
Option A: Freight Inclusive — user types the delivery location manually
Option B: Freight Extra at Actuals — Point of Delivery auto-fills as "Raipur, Chhattisgarh" by default
Client said: "When the user selects Freight Extra at Actuals, by default Point of Delivery should read as Raipur, Chhattisgarh. And if he says Freight Inclusive, then Point of Delivery is editable."
Step 15
Remove "Electricity Supply" from Terms & Conditions
Delete the "Electricity Supply: 220 Volts, Frequency 50 Hz" line from the terms & conditions section. Instead, add "220V Single Phase Supply" as a note line in the machine description area (below the item table), along with "Any other thing not mentioned above is not included in the supply."
Step 16
Warranty — Editable by Both User & Admin
The warranty field should be editable at both user and admin level. Default is 2 years. The client confirmed warranty should stay editable for negotiation purposes.
Step 17
Payment Terms — Editable by User
Payment terms (currently "50% Advance on PO, Balance before dispatch") should remain editable. User can change this based on customer negotiation.
Step 18
All Terms & Conditions — Make Flexible
Overall, the terms & conditions section should be flexible/editable. Users should be able to modify values per quotation based on customer discussion. Only Bank Details remain Admin-only.
↓ ↓ ↓
4

Quotation — Formatting Fixes

Why do this fourth? — Visual fixes that make the quotation look professional. These are quick fixes that improve first impression with customers.
Step 19
Logo Must Match on Both Quotation Types
The single-page quotation and multi-page (detailed) quotation currently show different logos. Both must use the same logo — matching the company letterhead.
Client said: "Uniform rehna chahiye, letterhead hai uniform rehna chahiye. It should match with the letter."
Step 20
Fix Left Margin — Content Closer to Left
The quotation PDF has too much space on the left. Content should start closer to the left side, like Microsoft Word formatting. Right margin can have some space.
Step 21
Fix Rupee Symbol & Table Formatting
In the detailed quotation, the ₹ (Rupee) symbol is taking too much space in the table, causing content to overflow to the next page. Fix the column width and number formatting.
Client said: "Yahan pe Rupees ka symbol ke wajah se zyada jagah le raha hai, uski wajah se wo neeche aa gaya hai." (The Rupee symbol is taking too much space, pushing content to the next page.)
↓ ↓ ↓
5

Technical Specification Auto-Fill

Why do this fifth? — The multi-page quotation has a technical sheet. Currently fields like "Number of Cameras" and "Number of Channels" are blank. They should auto-fill based on model + size selection.
Step 22
Auto-Fill Technical Specs Based on Model + Size
When user selects a model (e.g., Nandak) and size (e.g., 5 chute), the technical fields should auto-populate:
• Number of Modules & Channels
• Number of Cameras + Camera Specification
• Sorting Modes, Light System, Air Filter System, etc.
Client said: "Do hi select karte apan — model aur chute size. Uske saath number of cameras calculate karke likh dena, channels bhi. Taaki cross-fill karna na pade aur wrong entry na ho."
Step 23
Admin Can Set/Update Technical Specs Per Model
Admin should be able to configure the technical specification values for each model+size combination. When a new model launches, Admin adds it without contacting the developer.
Step 24
Client to Provide Tabular Data for Models
Client (Jna Ji) will share a tabular sheet with all model+size combinations for Nandak and Pinnacle — listing channels, cameras, and specs for each size. This data is needed to set up the auto-fill.
Action Item (Client): Jna Ji to share tabular data: Model → Size → Channels → Cameras → Specs for both Nandak and Pinnacle.

6

Sharing & Communication

Why do this sixth? — Sharing features work best once the quotation content and formatting are finalized. This includes email, WhatsApp, and notification features.
Step 25
Email & WhatsApp — Both Options + "Send Both at Once"
Keep Email, WhatsApp, and Download options. Add a 4th option: "Send Both" — sends via Email and WhatsApp in one click.
Client said: "Koi customer kehta hai WhatsApp nahi, mujhe email karo. We should have that option also. And both at once bhi chahiye."
Step 26
Send Quotation from App Directly (Not via Gmail Redirect)
Currently email sharing redirects to Gmail app. Instead, send email directly from the app with email address input field. PDF attachment should work properly (currently broken).
Step 27
Notify Superior When Quotation is Sent
When any user sends a quotation, their superior (Admin/Boss) should automatically receive a copy on their WhatsApp — so they know a quotation has gone out.
Step 28
Track Sharing History — Who Received, When
Admin should be able to see when a quotation was shared and to whom — for monitoring purposes. Currently no tracking since sharing goes through personal Gmail/WhatsApp.

7

Dashboard, Reporting & Other Decisions

Why do this last? — Dashboard and reporting features need data from all the above features to be meaningful. Other items need separate discussions.
Snapshot
Dashboard Snapshot — Intuitive Overview for Admin
Admin dashboard should show an intuitive snapshot: daily quotations generated, monthly quotation count, year-to-date total, graphs or tabular format. Filter by region, user, commodity, and machine size.
Client said: "Ek baar laptop mein khol liya toh intuitive aa jaana chahiye ki haan ye ab tak mera monthly ya is saal ka itna quotation generate hua hai."
Report
MIS Reports — Daily & Monthly (Admin Only)
Daily report of quotations and monthly averages. Also show which commodity + which machine size has the most demand — helps with stock forecasting.
Login
Persistent Login — Stay Logged In for a Day
Users should not have to login every time they open the app. Once logged in, stay logged in for at least one full day.
Decided
Authorized Signatory & Quotation Reference Number
Quotation will show "Authorized Signatory: Subhash" as-is. Reference number will be auto-generated by the system. No further discussion needed on these items.
